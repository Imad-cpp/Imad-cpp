## Purpose

This document prevents the public GitHub profile from drifting into unsupported or stale claims.

It records where education, certification, work and project statements come from and distinguishes personal history from official institution/program descriptions.

## Source priority

Use sources in this order for public profile facts:

1. the owner's latest explicit correction or decision;
2. the owner's current LinkedIn profile for personal chronology, roles, education entries and credentials;
3. official institution/program websites for descriptions of universities, faculties, programs and learning models;
4. GitHub repositories, commits, pull requests and project documentation for engineering evidence;
5. official public project websites for product-purpose/status context;
6. clearly labelled first-party narrative when a public external source does not exist.

Do not convert inference into fact.
